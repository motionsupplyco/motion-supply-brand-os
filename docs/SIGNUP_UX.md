# Signup confirmation UX

After a signup request that requires email confirmation, Brand OS should show a clear success state for the person who just signed up:

- Headline: `Check your email`
- Explain that a confirmation link was sent to the submitted address.
- Tell the user to check Spam or Promotions if it does not arrive right away.
- Keep Sign in and Forgot password available as low-friction fallback actions.

Do not lead with duplicate-account or provider-implementation language after every signup. New users should not be made to feel as if they already had an account.
