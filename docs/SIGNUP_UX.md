# Signup confirmation UX

After a signup request that requires email confirmation, Brand OS should show a clear next-step state for the person who just signed up:

- Headline: `Check your email`
- Tell the user to look for a confirmation link at the submitted address without claiming whether that address already had an account.
- Tell the user to check Spam or Promotions if the message does not arrive right away.
- Keep Sign in and Forgot password available as low-friction fallback actions.

Do not lead with duplicate-account or provider-implementation language after every signup. New users should not be made to feel as if they already had an account.
