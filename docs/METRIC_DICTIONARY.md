# Metric dictionary

All formulas below are formulas/frameworks, not universal performance benchmarks.

- Pre-CAC contribution = realized selling price - landed product cost - packaging - shipping subsidy - return/refund reserve - payment processor fee - affiliate cost.
- Contribution margin % = pre-CAC contribution / full-price revenue.
- Max first-order CAC = full-price pre-CAC contribution - founder-selected required contribution after CAC.
- CAC from spend = acquisition spend / new customers acquired in the same period.
- Break-even orders = fixed launch cost / contribution after CAC, rounded up. Requires positive post-CAC contribution.
- Store conversion rate = completed orders / sessions, same period/source.
- Add-to-cart rate = add-to-cart sessions / sessions.
- Checkout completion = completed orders / checkouts started.
- Reorder review point = base lead-time demand + scenario reserve. Scenario reserve = high-case lead-time demand - base lead-time demand when positive.
- Inventory position = on-hand + confirmed inbound - allocated/committed units.
- Weeks cover = freely available on-hand / base weekly unit demand.
- Wholesale contribution / unit = wholesale price - landed cost - wholesale handling - rep commission.
- Retailer gross-margin room = (MSRP - wholesale price) / MSRP. This is not the retailer's net profit.
- Normalized 3PL cost = variable 3PL cost / order + monthly minimum / monthly orders.
- Quick cash checkpoint = starting cash + expected inflows + wholesale receivable - committed outflows - taxes - payroll - supplier balances - processor hold.
- PO cash gate = quick cash checkpoint before proposed PO, then subtract deposit and full PO value and compare with the founder-selected protected cash floor.

Shopify Orders CSV metrics are labeled as export metrics, not Shopify Analytics net sales. Transaction history is used for captured/refunded payment cash summaries.
